# Public Release Scope

This repository is intentionally curated from the larger ABK_PAI V100 development package.

## Included
- Current V100 application entry point
- Supporting Python application/core code required by that entry point
- Runtime requirements
- Limited supporting assets and concept data used by the application
- V100 source README and test-results record for provenance

## Intentionally excluded
- Private or persistent classroom databases
- Historical/legacy application versions and old launchers
- Source-book archives
- Large training and problem-bank collections
- Development dictionaries and routing/training registries
- Internal manifests and extensive development changelogs
- Other internal development records not needed to establish the public digital contribution

The exclusions are deliberate: this GitHub release documents and demonstrates the software contribution without publishing the entire private development corpus.
