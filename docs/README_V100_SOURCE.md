# ABK_PAI Volume 100

ABK_PAI V100 is the cumulative replacement for V99.

## Start
Run `START_ABK_PAI_V100_BROWSER.bat`.

The V100 server uses port 8200 and opens `/v100/student-home`.

## V100 scope
- Canonical-problem Physics Tutor with structured line-by-line feedback.
- Teacher-assigned independent homework on one page.
- Teacher grading, correction, and written feedback returned to students.
- Student Portfolio access to grades and teacher feedback.
- `Not listed / Suggest new` options for Domain, Problem Family, Learning Mode, and RCs.
- Prompt Library context preservation for active Tutor problems.
- Correct Copy Prompt and Copy Equation behavior.
- Help page explaining Tutor, Assignments, Prompt Library, Equation Library, and grades.
- Browser spellcheck enabled on student and teacher free-text fields.

## Clean application
V100 launches `backend.main_v100:app`. The active V100 interface exposes one V100 route family and does not link to V96–V99 pages.
